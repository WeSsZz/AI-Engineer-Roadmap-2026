# Interview Preparation

## 项目讲解结构

1. 业务问题与为什么值得做
2. 最简单 baseline
3. 关键技术决策及备选方案
4. 数据集与评测方法
5. 真实结果与 trade-off
6. 失败案例和如何定位
7. 自己负责的部分
8. 如果再做一次会如何改进

## 必备主题

- Transformer：Attention、位置编码、训练目标、KV Cache
- RAG：切分、Embedding、Hybrid Search、Rerank、评测
- Agent：ReAct、Tool Calling、Workflow 边界、Memory、评测
- Fine-tuning：SFT、LoRA、QLoRA、数据质量、过拟合
- Engineering：异步任务、幂等、缓存、监控、服务拆分
