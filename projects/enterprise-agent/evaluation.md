# Evaluation

> 本文件只记录真实实验；初始模板中的数值保持为空。

## 数据集

- 语料来源：待定（必须公开或有分享权限）
- 文档数量：待测
- 问题数量：目标 80–100
- 标注方式：为每个问题标注相关文档/chunk，并抽检生成答案
- 数据划分：开发集与保留测试集分离

## 指标

### Retrieval

- Recall@5 / Recall@10
- MRR
- Rerank 后的 NDCG（可选）

### Answer

- 答案正确性
- 引用忠实度
- 无法回答时的拒答质量

### Agent

- 任务成功率
- 工具选择准确率
- 参数准确率
- 平均工具调用次数

### System

- P50 / P95 延迟
- 每请求 token 或估算成本
- 错误率
